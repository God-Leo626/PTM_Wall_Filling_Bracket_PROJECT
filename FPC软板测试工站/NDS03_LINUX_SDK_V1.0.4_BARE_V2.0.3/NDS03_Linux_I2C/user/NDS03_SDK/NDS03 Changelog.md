# Changelog

    NDS03 SDK所有值得注意的变化都将记录在这个文件中。

## [Unreleased]



## [2.0.3] - 2025-06

### **Fixed**

- 修复特殊场景下进行串扰标定失败的问题。
- 修复数据转换越界问题。

### **Added**

- 增加license。

### **Changed**

- 修改示例中变量初始赋值方式，兼容Keil编译。


## [2.0.2] - 2024-12

### **Fixed**

- 修复VCSEL异常时标定不报错的问题。

### **Added**

- 增加offset标定结果状态检测接口。


## [2.0.1] - 2024-10

### **Fixed**

- 修复无连接xshut引脚时，再次调用NDS03_WaitDeviceBootUp函数会出错的问题。

### **Added**

- 增加所有函数返回值判断，如果出错能立即返回。
- 增加判断是否为NDS03模组的函数接口。



## [2.0.0] - 2024-04

### **Changed**

- 修改i2c通信链接方式。
- 修改与中断相关的INT为GPIO1。
- 修改获取深度置信度等接口为连续读操作，减少I2C读取时间。

### **Added**

- 增加软件休眠接口。



## [1.0.0] - 2024-01

### **Added**

- SDK版本获取接口。
- offset标定/XTalk标定接口。
- 获取温度接口。
- 设置/获取发光次数接口。
- 设置/获取帧间隔时间接口。
- 设置/获取置信度阈值接口。
- 设置/获取目标个数接口。
- 设置/获取INT引脚中断功能接口。
- 设置/获取高/低深度阈值接口。
- 读写用户数据接口。
- 设备睡眠/唤醒接口。
- 设置I2C地址接口。
- 设备初始化接口。
- 等待设备启动接口。
- 单次测量接口。
- 连续测量接口。
